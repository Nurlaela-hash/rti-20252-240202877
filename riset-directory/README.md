# riset-directory (templated folders emptied)

Semua folder template di dalam `riset-directory/` telah dikosongkan kecuali:

- `01-proposal/proposal.md` (tetap)
- `05-kode/prototype/` (tetap)

Semua berkas asli yang dikosongkan disalin ke `riset-directory/archived/`.

Jika Anda ingin mengembalikan konten tertentu, salin dari `riset-directory/archived/`.
